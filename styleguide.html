Webflow Build Manifest

Styleguide

Every class, combo class, custom attribute and token to recreate natively in Webflow. The chip beside each example is the build recipe; the example element carries the real production markup. Values are sourced from assets/css/style.css.

Color/Green Native — Webflow Variable .text-size-m Native — class .border-faded Native — combo on a base class data-variant="outline" Custom code → global.css (not natively styleable) Used in build appears on a real page

Breakpoints: Desktop ≥992 (fluid vw) · ≤991 · ≤767. There is no ≤479 step (it inherits ≤767). Type sizes/weights/line-heights live on the classes — Webflow Variables can't hold vw.
