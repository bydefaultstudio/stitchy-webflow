Custom cursors

Native CSS cursor images (cursor: url()) — distinct from the bd-cursor.js tooltip system. Defined once in global.css as .cursor-* utility classes (base64 data URIs, PNG, no network fetch or URL drift); apply one by adding its class to an element in the Designer. Hover a swatch to preview. Desktop/pointer only — touch devices ignore custom cursors, so never carry meaning in the cursor alone.
